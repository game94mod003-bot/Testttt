ABULIX Scanner v2 - build with GitHub
1) Upload the CONTENT of this folder to the repo root (include .github/workflows/build.yml).
2) Actions > Build APK > Run workflow (also runs on every push).
3) Download Artifacts > Abulix-APK > app-debug.apk and install.
Release: push a tag like v2.0 and the APK is attached to a GitHub Release.
Note: sources now live as normal files under app/ (the old workflow generated them from embedded text).
